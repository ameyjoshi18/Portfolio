# ameyjoshi.in — Two Sides

Static site. No build step, no dependencies.

    index.html      home
    story.html      /story
    css/site.css    all styles
    js/site.js      thread, cutover, rails, reveals
    fonts/          self-hosted Archivo, Newsreader, Rozha One (all SIL Open Font License)
    favicon.svg
    vercel.json     static deploy, clean URLs (/story)

To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000
